## 02 / Selected Builds

### 🚑 [RESCUEPATH — Emergency Ambulance Route Optimizer](https://github.com/chmythresh/RESCUEPATH)
A route-optimization application exploring emergency ambulance routing using **Dijkstra, A\* and Floyd–Warshall**. Built with a **C++ Crow backend**, **React/Vite frontend** and **MySQL**, with deployment work on Render and Vercel.

`C++` `Crow` `React` `Vite` `MySQL` `Graph Algorithms`

### 🌾 AgriSense — Digital Farming Assistant
A farming operations dashboard with field health monitoring, sensor telemetry, irrigation scheduling and AI-assisted diagnostics. Built with **Spring Boot** and a **React/Vite** frontend.

`Java` `Spring Boot` `React` `H2 / MySQL` `REST APIs`

### 💊 PharmaFlow — Smart Pharmacy & Medicine Distribution
A pharmacy management project built around medicine inventory and distribution workflows.

`Java` `Spring Boot` `MySQL`

### 🤖 [AutoML Smart Prediction](https://github.com/chmythresh/AutoML-Smart-Prediction)
An AutoML and MLOps exploration combining model experimentation, API serving and deployment-oriented tooling.

`Python` `PyCaret` `MLflow` `FastAPI` `Docker` `GitHub Actions`
